Stage Exporter 1.6

- Checks GitHub for updates on every launch, with an install/restart prompt in Spanish or English.
- Verifies downloads using GitHub SHA-256; stages updates before copying and restores files on copy failure.
- Preserves existing user settings and all stage/cache files during in-app updates.
- Includes the current live add-on fixes and stage configurations, including nearby tree visibility tuning for Kenya. The far forest remains unchanged by this tuning.
- Includes the current export queue and stage controls.

Install: extract the ZIP and run INSTALAR.bat against Sando Rally Stage Export Tool 0.3.7. Open WRC to ACR Stage Exporter.exe.
Users of 1.5 or older need this manual installation once to receive future update prompts.
Rendering changes require rebuilding the affected stage; Update pack alone reuses the previous build.

Validation: Python syntax/config checks; updater version, checksum, path/file validation, settings preservation and rollback tests; real tree HISM generation and asset roundtrip. Tree pop-in improvement and FPS remain pending in-game validation.
